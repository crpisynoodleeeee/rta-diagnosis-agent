# 项目三 · RTA 投放诊断 Agent — 前端 Demo

> MVP 场景：项目配置了日预算，但实际消耗没有达到预期。用户在投放管理页面选择项目和日期后发起诊断，Agent 帮助定位预算为什么没有跑出去，并生成需要人工确认的处理方案。
>
> 不接真实媒体 API，不登录巨量后台，不修改真实预算和策略。

## 2. Demo 体验路径（Golden Case）

打开页面后会直接看到投放列表，第一行就是 Golden Case：

| 字段 | 值 |
|---|---|
| 项目 | 夏季大促项目（P-2026-SUMMER） |
| 日预算 | ¥1000 |
| 实际消耗 | ¥300 |
| 达成率 | 30%（红色进度条） |
| 异常状态 | 预算未达标 |

**操作步骤：**

1. 点击夏季大促项目行的「**发起诊断**」按钮
2. 右侧抽屉滑入 → 顶部状态变化 `读取数据中 → 诊断中 → 待人工确认`（约 3.3 秒）
3. 诊断完成后，抽屉内按 7 段式展示：
   - 01 一句话结论 + 管理摘要（折叠）
   - 02 影响概览（预算 / 消耗 / 差额 / 达成率）
   - 03 原因排序（主因 / 次因 / 已排除）
   - 04 证据时间线（11:50 配置变更 → 12:05 参竞率骤降）
   - 05 原因树（8 节点，点击展开看证据和指标）
   - 06 实验方案草稿（2 套方案可切换，调整前 / 后对比）
   - 07 技术详情（默认折叠，展开看 RTAID / 实验 ID / 请求 ID / 配置变更前后值）
4. 底部三按钮：**修改方案** · **拒绝** · **批准方案**
5. 点「批准方案」→ 进入 `等待人工执行`（提示已生成草稿，未改真实配置）
6. 点「确认已执行，等待数据回流」→ 进入 `等待数据回流`（展示 3 个回流指标）
7. 点「手动完成复盘」→ 进入 `复盘完成`（展示实验组参竞率和项目达成率回升）
8. 也可以点「拒绝」走 `诊断失败` 分支，再点「重新诊断」回到流程

**其它可验证的交互：**

- 原因树每个节点都能展开 / 收起，展开后看检查结论、关键证据、相关指标
- 技术详情默认折叠，展开后看 RTAID / 实验 ID / 分桶 / 请求 ID / 日志路径 / 配置变更前后值 / 数据来源
- 切换两个方案 Tab 看不同的「调整前 → 调整后」对比
- 术语对照表放在抽屉底部，把"参竞率 / RTA 超时 / 分桶 / 准入门槛"等行业黑话翻译成业务语言

## 5. 诊断状态机

```
未发起 ─→ 读取数据中 ─→ 诊断中 ─→ 待人工确认 ─→ 等待人工执行 ─→ 等待数据回流 ─→ 复盘完成
                                 ↘
                                  └→ 诊断失败 ─→ 重新诊断（回到 reading）
                                  
                         任意节点 ─→ 数据不足 ─→ 重新诊断
```

抽屉顶部状态徽章颜色规则：

- 灰色 — 未发起 / 数据不足
- 蓝色（脉冲点）— 读取数据中 / 诊断中 / 等待数据回流
- 黄色 — 待人工确认 / 等待人工执行
- 绿色 — 复盘完成
- 红色 — 诊断失败

## 7. 工程约束

- ✅ 本地 Mock 数据，不接真实媒体 API
- ✅ 不要求登录
- ✅ 不使用真实客户信息（账户名 / 主体 / 代理商全部脱敏）
- ✅ Mock 数据、页面组件、诊断状态、展示文案四层分离（见 `src/` 下结构）
- ✅ 首次打开即看到投放列表
- ✅ 所有点击操作有可见反馈（按钮 hover、状态切换、抽屉滑入、节点展开）
- ✅ 桌面端 1440px 宽度布局稳定（抽屉 720px，主区表格自适应）
- ✅ 不确定的真实接口字段保留为 Mock 字段并标注【待核验】
- ✅ 批准后只显示「已生成配置草稿，等待人工执行」，不修改真实配置

## 8. 后续接入真实 Agent 的路径

`demo/src/` 下保留了完整的 Vue 3 + TS 工程化骨架，接入真实 Agent 时：

1. `npm install` 装依赖
2. 把 `src/data/mock.ts` 中的 `goldenReport` 替换为真实 Agent 返回的 JSON
3. `src/composables/useDiagnosis.ts` 中的 `setTimeout` 替换为真实 API 调用
4. `src/types/index.ts` 中的 `DiagnosisReport` 接口作为 Agent 输出契约
5. 不确定的字段保留 `【待核验】` 标注，等联调确认后再去掉

`prototype.html` 单文件原型可以继续作为「产品演示 / 面试展示」用，不需要 Node 环境也能跑。
