## 完整状态流转路径

```
列表 → 点击「发起诊断」
   ↓
[读取数据中 1.2s] → [诊断中 1.8s] → [诊断完成]
                                          ├─→ 批准方案 → [等待人工执行] → 我已执行 → [等待数据回流] → 手动完成 → [复盘完成]
                                          ├─→ 修改方案 → [等待人工执行] → ...
                                          └─→ 拒绝方案 → [诊断失败] → 重新诊断 → [读取数据中]
                                          └─→ 任意节点可关闭抽屉
```

| 维度 | v1 (prototype.html) | v2 (index.html) |

| 主页面定位 | 「RTA 投放项目」直接展示 | 「RTA 配置」列表页，作为 RTA 子菜单入口 |
