# v0.8.0 - Read-only Provider Foundation

Status: Released on 2026-08-27

## Summary

V0.8 completes the four-batch foundation for controlled, read-only media data access. Mock records and replayed media-shaped responses now enter the diagnosis and assistant query paths through a shared Provider Envelope.

## Added

- `MediaDataProvider` contract with current-RTA scope, metadata and typed errors.
- `MockMediaDataProvider` for Demo record/list access.
- `ReplayMediaAdapter` for synthetic media response normalization, cache and freshness handling.
- Read-only tool whitelist for metrics, trends, group comparison, configuration changes and diagnosis evidence.
- Structured downstream degradation for stale, partial, insufficient, conflicting or failed Provider data.
- Provider source metadata retained alongside `EV-*` evidence.
- `_verify_v08_provider.cjs` with 34 validation cases.

## Boundaries

- All visible data remains synthetic Mock/Replay data.
- No real media API, production account, production credential or write operation is included.
- Staging API integration, real LLM tool calling, monitoring, audit and tenant governance remain V0.9 work.
