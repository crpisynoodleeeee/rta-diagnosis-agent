# v0.6.0 - RTA Diagnosis Agent Portfolio Demo

## Positioning

This release is a portfolio-grade, read-only RTA diagnosis Demo. It demonstrates a controlled Agentic Workflow for locating delivery bottlenecks, explaining causes and drafting low-risk experiments.

## Highlights

- D1-D14 deterministic rule engine.
- S0-S7 scenario recognition with three phenomenon tags.
- Seven-section diagnosis report and ten-state human confirmation flow.
- Optional local DeepSeek path with validation and template fallback.
- Restricted assistant for follow-up questions within the selected RTA diagnosis context.
- Offline Demo with local Vue and Tailwind vendor files.

## Evidence

- Golden Case validation.
- Five extended scenario narrative checks.
- Ten LLM path and safety checks.
- Forty-seven restricted assistant checks.

## Known limitations

The release uses synthetic Mock data. It does not connect to real media APIs, production accounts or live business metrics. The assistant does not perform cross-RTA historical analysis, industry benchmarking or configuration execution. GitHub Pages runs the template path by default.

## Next iteration

The next planned release will add queryable Mock data and read-only tool calls for trend comparison, experiment-group comparison, configuration-change lookup and evidence citation.
