# v0.9.1 - Public-Doc Field Contract Verification & Adapter Alignment

Status: Released on 2026-08-29

## Summary

V0.9.1 verifies the Staging Adapter field contract against 巨量开放平台公开接口文档 and aligns the adapter mappings while preserving the read-only boundary. Among 72 fields under review, 20 are verified, 27 partially verified, 19 have no public basis found, and 6 require real responses; the latter do not block this release. All offline acceptance groups remain green.

## Added

- 公开文档字段核验覆盖 RTA 策略管理（9 个接口）、OAuth2.0（5 个接口）、账户、数据报表、操作日志、枚举附录和返回码附录，共 28 份文档。15 个巨量业务码（`0` / `40000` / `40002` / `40100` / `40102` / `40103` / `40104` / `40107` / `40110` / `40113` / `40115` / `40118` / `40119` / `40130` / `50000`）映射为 5 类 `ProviderError`：`INVALID_REQUEST` / `PERMISSION_DENIED` / `AUTH_REQUIRED` / `RATE_LIMITED` / `UPSTREAM_UNAVAILABLE`。
- Adapter 对齐巨量公开契约：`rta_id` → `rtaId`、`interface_info.status`（`1/0`）→ `enabled/disabled`、`interface_info.url` → `bidUrl`（去除查询参数）、`local_qps/union_qps` → 分渠道 `qpsConfig`、原始保留 `delivery_range`、`list[].remark` → `strategies[].description`（不冒充 `name`）、`vid/cus_vid` → 互斥的 `bucketMode`（`platform/customer`）、`strategy 0-9` → `control/treatment`、`request_count/bid_count/convert/cost` → 指标、`bid_coef` → 分布维度，并对 `actualCpa` 的派生结果进行标注。
- Adapter 验收组由 8 项增至 14 项，新增 6 项 juliang 契约对齐用例，包含“不臆造字段”断言。

## Boundaries

- 零凭证：未调用任何 `/open_api/` 业务接口，未使用 token/secret，未发起真实媒体请求；本版本仅核验公开文档。
- `qpsUsed/qpsRemaining`、`changes[].operator` 脱敏行为，以及回传三项指标（`callbackSuccessRate` / `callbackLatency` / `missingFieldRate`）共 6 项需真实响应确认，不阻塞封版。
- `dataUpdatedAt` 不是公开字段；t+1/t+5 仅表示可查询时间口径，不得用 `fetchedAt` 替代。
- 不引入任何写接口；`capabilities.readOnly = true` 保持。预算、成本、转化和 CPA 属于报表/扩展口径，不是 RTA 原生配置收益字段。
- 本版本不表述为已完成真实媒体 API 联调或业务收益验证。
