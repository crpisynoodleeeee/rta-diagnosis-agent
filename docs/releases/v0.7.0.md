# v0.7.0 - Queryable Mock Evidence Layer

Status: Released on 2026-08-26

## Summary

v0.7 adds a read-only Mock query layer for the selected RTA. The assistant can now answer current-RTA metric, trend, control/treatment comparison, configuration change and evidence questions with stable `EV-*` evidence references.

## Added

- `QueryContext` generated from the selected RTA Mock record and `DiagnosisReport`.
- Stable evidence IDs for metrics, trend points, configuration changes, groups, rules, scenarios and cause nodes.
- Read-only query tools inside `demo/V1.0/index.html`: metrics, trend comparison, group comparison, configuration changes and diagnosis evidence.
- Schema/data-quality validation for missing fields, duplicate evidence IDs, time-order issues and metric conflicts.
- Refusal/degradation for data insufficiency, evidence conflicts, trend points below 2 and cross-RTA questions.
- LLM assistant guardrail requiring query answers to cite valid `EV-*` evidence IDs.
- `_verify_v07.cjs` with 30 validation cases.

## Boundaries

- All data remains synthetic Mock data.
- Querying is limited to the selected RTA and current Mock data range.
- No real media API, production account, production data, write operation or automated execution is included.
- Cross-RTA history, industry benchmarks and real-time media status remain out of scope.
