# v1.0.0 - V1.0 可治理诊断决策闭环（Mock-Ready）——工作台先行版 + 治理闭环 + 证据面板产品化

Status: Released on 2026-08-31

## Summary

V1.0.0 发布可治理诊断决策闭环（Mock-Ready），以异常诊断工作台为入口，形成从诊断、证据、处置草稿、人工审批、执行记录、观察到复盘关闭的完整模拟闭环，并将证据面板与业务语言产品化。治理核心仍为纯前端 Mock 领域层，未接入真实媒体 API 或生产基础设施。

## Added

### 异常诊断工作台（P5）

- 任务队列支持待关注、数据不足、待审批、观察中计数与筛选 tab。
- 任务详情提供任务摘要、判断过程五步、判断依据三组证据、下一步动作四件套。
- 数据不足或数据过期时进入对应分支，不生成伪结论。
- 语境化智能参谋通过 `blockedTopics` 执行拒答。

### 可治理诊断闭环（V1.0）

- 提供 observer / optimizer / approver 角色与最小权限控制，领域层一致拒绝并保留审计留痕。
- 提供处置草稿与人工审批状态机：`draft` → `pending_approval` → `approved/rejected` → `execution_recorded` → `observing` → `reviewed` → `closed`。
- 提供审计时间线，以及 `normal` / `stale` / `partial` / `timeout` / `permission_denied` / `cross_tenant_denied` 稳定性与降级状态可视化。
- 提供观察与复盘闭环。

### 纯前端 Mock 治理领域层

- 治理核心位于 `demo/v6/governance/`，为 Mock-Ready 的纯前端 Mock 领域层。
- 租户隔离、Token 轮换、限流熔断、审计不可篡改仅为契约设计与离线测试，未建设生产基础设施。

### 证据面板产品化（P3）

- 证据按支持当前判断、已排除的原因、当前仍需确认三类分组。
- 提供数据质量摘要、`EV-*` 编号与可折叠的技术详情。

### 业务语言收口

- 页面主层级统一为投放优化师视角：异常任务、投放对象、异常类型、数据状态、处理状态、建议动作；判断过程、判断依据、处理进度、处理操作、操作记录、诊断助手、完整诊断报告。

## Boundaries

- 全部业务数据为合成 Mock/Replay，未接入真实媒体 API、未使用真实凭证、未发真实请求。
- 不直接修改预算、出价或策略；处置草稿人工审批为模拟流程（零真实写接口）。
- 真实媒体 API 联调待企业主体授权（外部条件成就项，不阻塞本版本）。
- 租户隔离、密钥托管、限流熔断等为契约设计 + 离线测试，非生产基础设施。
