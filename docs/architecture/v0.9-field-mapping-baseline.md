# V0.9 字段映射基线

## 1. 目的与约束

本文锁定 V0.9 Staging 只读 Adapter 的规范化字段。字段路径以 V0.8 `MediaDataProvider` 契约及现有 `MockMediaDataProvider` / `ReplayMediaAdapter` 为准；真实媒体响应字段尚未取得，不在本阶段臆造。表中“现有字段名”均指规范化输出字段，真实上游字段名、枚举和值域须在接入前核验。

- 契约版本保持 `0.8`，数据范围保持 `current_rta_only`。
- `getConfigSnapshot`、`getMetricBundle`、`getDataEnvelope` 的返回结构不变。
- 比例统一使用 `[0, 1]` 小数；金额统一按“元”；耗时统一按“毫秒”；QPS 为“次/秒”；计数为非负整数。
- 时间戳对外统一为带时区的 ISO 8601 字符串。仅展示用的 `trend[].time` 可保留时间桶标签，但 Adapter 内部必须先取得带时区的时间桶边界。
- `budget` 及 CPA 字段是 Demo 扩展口径，不得宣称为 RTA 原生字段。Golden Case 固定为准入门槛 `40% → 80%`、参竞率 `60% → 10%`、建议 `80% → 60%`。

## 10. Provider 元数据

规范化结果必须保留 V0.8 `ProviderEnvelope.meta`：`providerId`、`platform`、`sourceRecordId`、`schemaVersion`、`fetchedAt`、`dataUpdatedAt`、`freshnessSeconds`、`qualityStatus`、`missingFields[]`。其中 `schemaVersion` 仍为 `0.8`；`qualityStatus` 的观测口径由安全审计设计统一定义。

## 11. 外部 API 文档待补 delta 清单

| Delta | 必须补齐的内容 | 锁定/阻塞条件 |
| --- | --- | --- |
| 分页方式 | cursor/page/offset 类型、页大小、结束条件、跨页一致性、最大页数 | 未确认前不得实现无界翻页 |
| 限流策略 | 租户/Token/接口维度、QPS/并发额度、响应头、配额恢复时间 | 未确认前只可使用保守本地上限，不可声称符合上游配额 |
| 超时上限 | 连接、首字节、单页、整次调用上限 | 必须小于调用链总预算，并由 AbortController 强制终止 |
| 重试语义 | 可重试状态、`Retry-After`、幂等性、最大次数、退避与抖动 | 仅允许 `RATE_LIMITED`、`TIMEOUT`、`UPSTREAM_UNAVAILABLE` |
| 错误码表 | HTTP 状态、业务码、错误体 schema、权限与资源不存在区分 | 必须映射到既有 12 类 `ProviderError`，不得新增错误码 |
| 数据更新时间口径 | `dataUpdatedAt` 来源、时区、延迟、补数、最终一致性及 freshness SLA | 未确认时不得把 `fetchedAt` 当作 `dataUpdatedAt` |

除以上横向 delta 外，前述每张表的“待外部核验项”均须在 Staging 授权后逐项关闭；关闭记录应标注文档版本与核验日期。
