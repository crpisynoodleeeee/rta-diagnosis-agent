# 1. Apple Ads App 接入与整体归因链路
## 1.1 功能定位
Apple Ads App 接入用于建立客户 iOS App、XAD 事件中心、XAD Apple Ads 归因解析服务和 Apple AdServices Attribution API 之间的归因解析链路。

Apple Ads App 不使用 XAD 投放链接、短链、中转页、监测链接或媒体 callback 完成归因，也不进入 XAD 传统归因策略和回传策略。

本模块负责：

1. 明确客户 App 获取 Apple attribution token 的接入方式。
2. 明确客户系统向 XAD 事件中心上报 token 及应用上下文的方式。
3. 明确 XAD 请求 Apple AdServices Attribution API 的处理链路。
4. 明确 Apple 请求失败后的自动重试机制。
5. 明确 Apple 返回结果的解析、标准化和事件中心入库方式。
6. 为 Apple Ads 归因解析日志和 Apple Ads 归因报表提供数据来源。

---

## 1.2 整体归因链路
Apple Ads App 的标准归因链路为：

客户 App 获取 attribution token → 客户系统通过事件中心将 token 及上下文同步至 XAD → XAD 请求 Apple → XAD 自动重试和解析 → XAD 内部生成 Apple Ads 归因解析事件 → 归因解析日志与归因报表使用该事件。

具体处理步骤如下：

| 步骤 | 处理方 | 处理说明 |
| --- | --- | --- |
| 1 | 客户 iOS App | 接入 Apple AdServices Framework，在 App 首次打开或约定触发时机获取 attribution token |
| 2 | 客户 App / 客户系统 | 将 attribution token、应用标识、事件时间及必要上下文上报至客户服务端 |
| 3 | 客户系统 | 通过 Kafka 将 Apple Ads Token 事件同步至 XAD 事件中心 |
| 4 | XAD 事件中心 | 接收 Token 事件并投递至 Apple Ads 归因解析服务 |
| 5 | XAD 归因解析服务 | 校验 XAD 应用 ID、App Store ID、Bundle ID 等应用信息 |
| 6 | XAD 归因解析服务 | 对 Token 事件执行幂等校验，避免同一 token 重复发起解析 |
| 7 | XAD 归因解析服务 | 使用 attribution token 请求 Apple AdServices Attribution API |
| 8 | XAD 归因解析服务 | 请求失败时，根据系统重试规则自动重试 |
| 9 | Apple | 返回 Apple Ads attribution Payload-暂时不做 或无归因结果 |
| 10 | XAD 归因解析服务 | 解析 Apple 返回结果，并标准化 Apple Ads 层级及归因字段 |
| 11 | XAD 归因解析服务 | 在 XAD 内部生成 Apple Ads 归因解析事件并写入事件中心 |
| 12 | XAD | 基于 Apple Ads 归因解析事件生成归因解析日志和归因报表 |

## 1.4 事件中心接入方式
Apple Ads App 归因链路通过 XAD 事件中心完成数据接入和结果沉淀。

本期涉及两类事件：

| 事件类型 | 生成方 | 说明 |
| --- | --- | --- |
| Apple Ads Token 事件 | 客户系统 | 携带 attribution token、应用标识、事件时间及必要上下文，用于触发 XAD 请求 Apple |
| Apple Ads 归因解析事件 | XAD 系统 | 存储 XAD 请求 Apple 后生成的处理状态、归因结果及 Apple Ads 层级字段 |


处理规则：

1. 客户系统仅负责同步 Apple Ads Token 事件。
2. Apple Ads 归因解析事件由 XAD 请求 Apple 并完成解析后内部生成。
3. Apple Ads 归因解析事件不是客户系统直接同步的 Apple 返回结果。
4. Apple Ads 归因解析日志以 Apple Ads 归因解析事件为数据来源。
5. Apple Ads 归因报表基于 Apple Ads 归因解析事件进行聚合统计。
6. 本期标准能力不依赖客户激活、注册、开户、交易、付费等业务事件。

---

## 1.5 客户侧接入要求
客户 iOS App 需要接入 Apple AdServices Framework，并在约定时机获取 attribution token。

客户系统需将 token 和必要上下文同步至 XAD 事件中心。

建议上报信息如下：

| 信息 | 是否必填 | 说明 |  |
| --- | --- | --- | --- |
| <font style="background-color:#FBDE28;">platform</font> | <font style="background-color:#FBDE28;">是</font> | <font style="background-color:#FBDE28;">建议输入渠道名称，此处适配多媒体接入的情况</font> |  |
| attribution token | 是 | Apple AdServices Framework 返回的归因 token |  |
| XAD 应用 ID / APP ID | 是 | 用于匹配 XAD 应用管理中的 Apple Ads App |  |
| App Store ID | 是 | Apple App Store 应用标识 |  |
| Bundle ID | 是 | iOS 应用 Bundle ID |  |
| 事件时间 | 是 | token 获取时间或 App 打开时间 |  |
| App 打开事件 ID | 建议 | 用于幂等和问题排查 |  |
| User ID | 可选 | 客户业务侧用户标识 |  |
| IDFV | 可选 | 客户侧排查辅助字段 |  |
| App 版本 | 可选 | 客户 App 版本 |  |
| iOS 版本 | 可选 | 客户设备系统版本 |  |


产品规则：

1. attribution token 仅用于 XAD 服务端请求 Apple 归因解析。
2. attribution token 不作为 XAD 归因匹配字段使用。
3. attribution token 不在前端页面明文展示。
4. attribution token 不依赖 IDFA。
5. 客户未上报 attribution token 时，不生成有效 Apple 请求任务。
6. 客户业务事件不属于本期标准接入要求。

---

## 1.6 XAD 处理要求
XAD 接收到 Apple Ads Token 事件后，需要完成以下处理：

| 处理能力 | 说明 |
| --- | --- |
| 应用匹配 | 根据 XAD 应用 ID、App Store ID、Bundle ID 匹配应用管理中的 Apple Ads App |
| 幂等校验 | 避免同一 token 或同一 App 打开事件重复请求 Apple |
| Apple 请求 | 使用 attribution token 请求 Apple AdServices Attribution API |
| 自动重试 | 对符合条件的临时异常执行系统自动重试 |
| 结果解析 | 解析 Apple 返回的 attribution  |
| 字段标准化 | 将 Apple Ads 层级和归因结果转换为 XAD 标准展示信息 |
| 异常记录 | 记录应用不匹配、token 无效、Apple 请求失败、字段解析失败等异常 |
| 事件生成 | 在 XAD 内部生成 Apple Ads 归因解析事件 |
| 日志输出 | 将单次处理结果提供给 Apple Ads 归因解析日志 |
| 报表输出 | 将解析结果提供给 Apple Ads 归因报表聚合 |


---

## 1.7 自动重试规则
Apple Ads 归因解析支持系统自动重试，但不提供用户手动重试入口。

| 场景 | 是否自动重试 | 说明 |
| --- | --- | --- |
| 请求 Apple 超时 | 是 | 按系统重试规则重新发起请求 |
| 网络异常 | 是 | 按系统重试规则重新发起请求 |
| Apple 服务临时异常 | 是 | 按系统重试规则重新发起请求 |
| XAD 临时处理异常 | 是 | 满足可重试条件时重新执行 |
| attribution token 缺失 | 否 | 参数不完整，直接记录失败 |
| attribution token 无效 | 否 | Apple 明确返回 token 无效时，不继续重试 |
| 应用信息未匹配 | 否 | 需先补充或修正应用配置 |
| 事件格式异常 | 否 | 客户上报事件不符合接入要求 |
| 幂等校验重复 | 否 | 不重复请求 Apple |


补充规则：

1. 自动重试次数及间隔由技术方案确定。
2. 前端日志展示当前处理状态、自动重试次数和最终失败原因。
3. 自动重试属于 Apple 归因解析任务处理，不属于传统媒体回传重试。
4. 超过最大重试次数后，处理状态变更为“处理失败”。
5. 自动重试次数及重试间隔需在技术评审阶段确认。

---

## 1.8 处理结果
Apple Ads 归因解析需要区分“Apple 解析状态”和“归因状态

### 1.8.1  Apple 解析状态
| 状态 | 说明 |
| --- | --- |
| 待处理 | Token 事件已进入 XAD，尚未开始请求 Apple |
| 处理中 | XAD 正在请求 Apple 或解析返回结果 |
| 重试中 | 首次请求失败，系统正在自动重试 |
| 处理成功 | 已正常完成 Apple 请求及结果解析 |
| 处理失败 | 参数校验失败，或超过最大重试次数后仍未成功 |


### 1.8.2 归因状态
| #### 归因状态 | 说明 |
| --- | --- |
| 归因成功 | Apple 返回 attribution = true |
| 无归因结果 | Apple 正常返回，但 attribution = false 或未返回有效 Apple Ads 归因 |
| 未知 | 请求或解析流程未成功完成，无法判断归因结果 |


规则：

1. 处理成功不等于归因成功。
2. 无归因结果不属于系统异常。
3. 处理失败时，归因结果展示为“未知”。
4. 归因解析日志和归因报表需分别使用处理状态与归因结果，不得混为同一状态。

---

## 1.9 数据使用范围
Apple Ads 归因解析事件仅用于：

1. Apple Ads 归因解析日志展示。
2. Apple Ads Campaign、Ad Group、Keyword 等层级归因分析。
3. Apple Ads Download / Redownload 分析。
4. Apple Ads 产品页 / CPP 相关分析。
5. Apple Ads 归因结果汇总和趋势分析。

本期不用于：

1. XAD 传统归因策略条件匹配。
2. XAD 回传策略执行。
3. 传统媒体 callback 回传。
4. 激活、注册、开户、交易、付费、留存等业务事件关联分析。
5. 业务事件去重和关联窗口计算。
6. 项目侧定制转化指标计算。

业务转化类能力可作为项目侧定制口径使用，由具体项目单独评估事件接入、关联关系和统计规则，不纳入本期标准能力。

| 未知 | 请求或解析流程未成功完成，无法判断归因结果 | |


规则：

1. 处理成功不等于归因成功。
2. 无归因结果不属于系统异常。
3. 处理失败时，归因结果展示为“未知”。
4. 归因解析日志和归因报表需分别使用处理状态与归因结果，不得混为同一状态。



#### 失败说明包括：
1. attribution token 缺失。
2. attribution token 失效。
3. 请求 Apple 接口失败。
4. Apple 返回异常。
5. Apple 返回字段缺失。
6. ~~App Store ID / Bundle ID 未匹配到 XAD 应用~~
7. <font style="background-color:#FBDE28;">系统处理异常（Kafka 消息格式异常，字段标准化失败，幂等校验失败）</font>
