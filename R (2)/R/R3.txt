## 3.1 RTA 技术原理
RTA（Real-Time API）是一种允许广告主在程序化广告竞价过程中实时参与决策的技术。当 DSP 或媒体广告平台收到广告请求时，会同步调用广告主提供的 RTA 接口。

广告主可基于自身第一方数据、用户画像、转化数据、风控数据、模型预估结果等，实时判断当前用户是否需要参竞，并返回参竞、不参竞或出价调节结果。

RTA 的核心价值是让广告主在媒体竞价链路中使用自有数据完成实时判断，从源头降低无效投放成本，并提升后链路转化质量。

---

## 3.2 需求背景
当前平台已具备 RTA 策略工厂、RTA 实验、RTAID 配置、RTA 数据中心等基础能力，并已支持巨量、腾讯的 RTA 管理能力。

本期需要新增华为 RTA 接入能力，并同步优化现有 RTA 产品体验，重点包括：

 策略工厂支持华为媒体。  
 RTAID 配置支持华为媒体、SecretKey、媒体账户绑定和 QPS 使用情况回显。  
 华为 RTA 支持出价系数、CPA 出价、CPC 出价。  
 AB 实验新增客户分桶，由平台侧根据用户配置的分桶字段自主完成分组。  
 RTAID 系统配置中的平台分桶 ID 仅针对平台分桶生效。  
 策略工厂新增人群覆盖预估。  
 RTA 实验选择策略后回显策略覆盖人数。  
 普通实验和 AB 实验均支持策略组配置能力。  
 RTA 报表和执行日志支持华为媒体数据。

本期不调整 RTA 数据中心页面结构，不新增华为专属报表指标和日志字段体系。

---

## 3.3 需求目标
1. 新增华为 RTA 接入能力，使华为可在 RTAID、策略工厂、RTA 实验、数据中心中使用。
2. 支持华为 RTAID 配置，包括 BidURL、媒体账户、SecretKey、QPS、状态等信息维护。
3. 支持华为基础出价映射，包括出价系数、CPA 出价、CPC 出价。
4. 支持华为出价系数范围校验，priceWeight 需大于 0 且小于等于 50。
5. 优化策略工厂新建 / 编辑能力，支持华为生效范围、媒体账户选择、字段配置和人群覆盖预估。
6. 优化 RTA 实验配置，支持按当前 RTAID 筛选可用策略，并在选择策略后回显对应人群覆盖人数。
7. AB 实验新增客户分桶能力，由平台自主完成分组，以支持华为等不支持官方分桶的媒体。
8. 基础配置中的分桶 ID 配置仅针对平台分桶生效，客户分桶不读取该配置。
9. RTAID 和 RTA 实验中实时回显 QPS 使用情况，告知用户当前实验已占用 QPS 和剩余 QPS。
10. RTA 数据中心支持华为媒体数据展示。

# 六、整体流程说明
## 6.1 华为 RTA 接入流程
华为 RTA 请求进入平台后，系统先识别媒体、RTAID、账户和设备标识，再根据 RTAID 读取 SecretKey 进行签名校验。

签名校验通过后，系统读取 RTAID 配置和实验配置。如果请求命中 AB 实验，则根据实验配置的分桶方式进入对照组或实验组；如果未命中 AB 实验，则进入普通实验或策略判断流程。

最终系统根据命中的策略返回参竞、不参竞或出价结果，并记录到现有执行日志和报表数据中。

![](https://cdn.nlark.com/yuque/__mermaid_v3/de9d02bbb1d5c866d00e897029798a32.svg)

---

## 6.2 AB 实验分桶流程
AB 实验支持平台分桶和客户分桶。

平台分桶依赖媒体侧传入桶 ID，并与系统配置中的分桶 ID 进行匹配。若媒体未传桶 ID，或传入桶 ID 与系统配置不匹配，则执行对照组策略。

客户分桶不依赖媒体侧桶 ID。系统根据 AB 实验中配置的客户分桶字段，获取可用字段值并计算桶号，再根据 AB 实验页面中的桶分配结果进入对应实验组或对照组。

## 8.2 策略状态与操作规则
### 状态说明
| 状态 | 状态说明 | 支持操作 | 限制规则 |
| --- | --- | --- | --- |
| 草稿 | 策略已创建但未发布，不可被实验引用。 | 查看、编辑、删除、发布、复制 | 不可被普通实验或 AB 实验选择。 |
| 已发布 | 策略已发布，可被普通实验和 AB 实验引用。 | 查看、复制、下线、查看数据报表 | 不允许直接编辑、删除。 |
| 已下线 | 策略已从可引用状态下线，不允许被新增实验引用。 | 查看、编辑、发布、停用、复制、查看数据报表 | 已有关联实验和历史数据需保留。 |
| 已停用 | 策略停止生效。 | 查看、复制、查看数据报表 | 不允许被新实验引用；不支持重新启用，如需再次使用，需复制后重新创建。 |


### 状态流转规则
1. 草稿策略发布后，状态变更为「已发布」。
2. 已发布策略下线后，状态变更为「已下线」。
3. 已下线策略可重新发布，发布后状态恢复为「已发布」。
4. 已下线策略可编辑，编辑后可保存或重新发布。
5. 已停用策略不可恢复为已发布，如需再次使用，需复制策略后重新创建。
6. 已有关联实验或历史数据的策略，不允许物理删除，仅允许下线或停用。
7. 删除操作仅支持草稿状态。

## 8.3 新建 / 编辑策略
### 入口 / 路径
RTA → 策略工厂 → 新建策略  
RTA → 策略工厂 → 编辑策略

### 页面类型
右侧抽屉或独立编辑页。

### 功能说明
新建 / 编辑策略用于配置可复用的 RTA 策略。用户需要选择适用媒体、媒体侧 RTA 策略 ID / RTAID、策略类型、参竞策略、出价方式、数据源及字段配置。

编辑态不支持修改适用媒体和媒体侧 RTA 策略 ID / RTAID。如需变更媒体或 RTAID，用户需复制策略后重新创建。

### 优化点 4：新建 / 编辑 / 预览页面新增人群覆盖预估
新建 / 编辑策略页面底部新增「人群覆盖预估」模块，用于帮助用户在保存或发布策略前，快速了解当前策略所配置用户字段可覆盖的人群规模。

### 自动更新规则
人群覆盖预估需支持自动更新。

自动更新触发时机如下：

1. 用户新增字段 ID 后，系统自动触发覆盖人数计算。
2. 用户编辑字段 ID 后，系统自动触发覆盖人数重新计算。
3. 用户切换数据表或数据库后，如字段配置发生变化，系统需重新计算。
4. 用户修改字段类型，导致用户字段发生变化时，系统需重新计算。
5. 用户删除用户字段后，系统需清空原覆盖人数，并展示对应空状态。

自动更新过程中，模块需展示计算中状态。

### 手动更新规则
模块下方提供「计算人群」按钮，支持用户手动刷新覆盖人数。

适用场景如下：

1. 用户希望主动重新计算覆盖人数。
2. 自动计算失败后，用户点击按钮重试。
3. 用户怀疑数据源有更新，希望手动触发刷新。
4. 用户调整字段配置后，需要立即查看最新覆盖结果。

按钮文案：

计算人群

交互规则如下：

1. 点击「计算人群」后，系统重新计算当前字段配置下的人群覆盖人数。
2. 计算中按钮进入 loading 状态。
3. 计算中不允许重复点击。
4. 计算成功后，刷新总覆盖人数和各字段覆盖人数。
5. 计算失败时，展示失败提示，并允许用户再次点击计算。

6. 人群覆盖预估结果不阻断策略保存或发布，仅作为配置辅助信息展示。

## 8.4 生效范围说明
不同媒体的策略生效范围不同，需根据适用媒体展示对应规则。

### 巨量
当适用媒体为巨量时，展示「生效范围」配置项，用户可选择账户或项目。

规则如下：

1. 选择「账户」时，无需进一步选择具体账户。
2. 选择「账户」后，页面提示：“当前 RTAID 关联的所有账户及项目将使用该 RTA 策略。”
3. 选择「项目」时，需选择具体项目。
4. 仅被选择且已关联当前 RTAID 的项目使用该策略。
5. 未选择或未关联当前 RTAID 的项目不使用该策略。

### 腾讯
当适用媒体为腾讯时，展示「生效范围」，但不支持用户选择账户或项目。

规则如下：

1. 生效范围默认按当前 RTAID 绑定关系生效。
2. 页面可展示为「默认」或「当前 RTAID 绑定范围」。
3. 用户不可手动切换账户或项目。
4. 建议提示：“腾讯策略默认按当前 RTAID 绑定关系生效，无需单独选择账户或项目。”

### 华为
当适用媒体为华为时，展示「生效范围」，但不支持用户选择账户或项目。

规则如下：

1. 生效范围默认按当前 RTAID 绑定关系生效。
2. 页面可展示为「默认」或「当前 RTAID 绑定范围」。
3. 用户不可手动切换账户或项目。
4. 建议提示：“华为策略默认按当前 RTAID 绑定关系生效，无需单独选择账户或项目。”

### 字段匹配逻辑

3. 多个用户字段同时存在时，系统逐一匹配用户字段 ID。

5. 模型字段不参与人群覆盖预估，但可参与模型判断或模型出价。

## 9.4 华为 SecretKey 规则
华为 RTA 请求需要基于 SecretKey 进行签名校验。本期在华为 RTAID 配置中维护 SecretKey。

默认签名口径为：

```plain
HmacSha256(requestId + requestTime + oaid)
```

若华为请求中无 OAID，签名字段拼接规则需由客户 / 华为侧在联调前预先约定。平台不默认推断无 OAID 场景下的签名拼接方式。

## 9.5 QPS 展示&配置与计算规则
### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">核心定义与通用计算公式</font>
#### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">RTAID 维度 QPS（单 RTAID 粒度）</font>
+ **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">配置 QPS</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：单个 RTAID 的请求上限，由用户手动配置</font>
+ **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">实验已占用 QPS</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：当前 系统/RTAID 下所有已创建实验（启用状态）占用的 QPS 总和，系统实时计算回显，只读不可编辑</font>
+ **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">剩余 QPS</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：当前 RTAID 可用于新增 / 调整实验的可用额度</font>
+ **<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">使用率</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">：当前 RTAID 的实验资源占用比例</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">计算公式：</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">剩余QPS = 当前系统/RTAID配置QPS - 实验（启用状态）已占用QPS</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">使用率 = 实验已占用QPS / 配置QPS</font>

#### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">RTAID 上限基础计算逻辑</font>
1. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">若当前 RTAID 无实验，实验已占用 QPS 展示为 0</font>
2. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">若当前 RTAID 已有实验，实验已占用 QPS 展示所有实验的占用总和</font>
3. <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">用户调整配置 QPS 后，页面实时刷新剩余 QPS 数值</font>

#### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">生效判断规则</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">剩余 QPS ≥ 0：操作成功，允许保存 / 发布</font>
+ <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">剩余 QPS < 0：操作失败，不允许保存 / 发布</font>



### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);"> 展示入口 1：RTAID 配置列表 - 系统 QPS 概览卡片</font>

## 9.6<font style="background-color:#FBDE28;"> 空设备 ID 兜底策略 删除待定</font>
### <font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">功能定位</font>
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">用于处理请求中缺少可用于识别用户设备 ID 的场景。本期在原有参竞比例、出价系数基础上，新增 CPA、CPC 出价兜底字段；系统执行时无固定优先级，根据当前命中的出价方式动态取对应兜底字段。</font>

## 10.4 平台分桶 ID 配置
平台分桶 ID 配置用于维护不同媒体下的分桶 ID 映射关系。当 AB 实验选择平台分桶时，系统根据媒体请求中传入的桶 ID 与此处配置进行匹配。

该配置仅针对平台分桶生效，客户分桶不读取该配置。

华为 RTA 不支持官方分桶，因此华为不读取平台分桶 ID 配置。

| 客户分桶 | 否 |
| 华为 RTA | 否 |
| 平台自主计算桶号 | 否 |


### 配置规则

客户分桶：

### 分桶方式规则

| 配置项 | 规则 |
| --- | --- |
| 默认实验组 | 默认生成 1 个对照组 + 1 个实验组 |
| 新增实验组 | 支持新增多个实验组 |
| 对照组 | 对照组不可删除 |
| 分桶数量 | 固定 10 个桶 |
| 单桶流量 | 每桶默认代表 10% 流量 |
| 分桶分配 | 每个组至少选择 1 个分桶 |
| 分桶唯一性 | 同一分桶不可重复分配给多个组 |
| 流量占比 | 根据各组分配桶数自动计算 |
| 总占比 | 各组分桶占比总和不得超过 100% |
| 发布后修改 | 发布后不可直接修改分桶，需按现有实验编辑规则处理 |


平台分桶和客户分桶共用同一套分桶分配页面。

差异仅在于桶号来源：

 平台分桶：桶号来自媒体传入，并与系统配置的平台分桶 ID 匹配。  
 客户分桶：桶号由平台根据客户分桶字段配置计算生成。

### 分桶兜底规则
| 分桶方式 | 异常场景 | 处理方式 |
| --- | --- | --- |
| 平台分桶 | 媒体未传桶 ID | 执行对照组策略 |
| 平台分桶 | 桶 ID 为空 | 执行对照组策略 |
| 平台分桶 | 桶 ID 不匹配 | 执行对照组策略 |
| 平台分桶 | 桶 ID 格式异常 | 执行对照组策略 |
| 客户分桶 | 匹配异常 | 执行对照组策略 |
| 客户分桶 | 分桶计算失败 | 执行对照组策略并记录异常 |

## 11.6 配置实验
配置实验用于维护实验下的策略组合。

全局配置区保持现有逻辑不变。

普通实验和 AB 实验均复用策略组配置能力。普通实验直接配置策略组；AB 实验需在对照组和各实验组内分别配置策略组。

每个策略组内可添加多条策略，并支持按逻辑关系组合。

### 策略组配置区
字段与组件：

「策略组容器」：用于承载当前实验下全部策略组。默认生成 1 个策略组。  
「新增策略组」：点击后新增一个新的策略组。新策略组默认命名为“策略组 N”。  
「策略组名称」：输入框，必填，默认按“策略组 1 / 策略组 2”生成，支持用户手动修改。  
「删除策略组」：删除当前策略组。  
<font style="background-color:#FBDE28;">「组内逻辑关系」：单选，支持““或（OR）”</font>  
「添加」：点击后，在当前策略组内新增一条策略配置行。  
「删除策略」：删除当前策略组内某条策略；若当前策略组仅剩 1 条策略，删除后保留空白态，不自动删除整个策略组。

### AB 实验中的策略组规则
| 场景 | 规则 |
| --- | --- |
| 对照组 | 至少配置 1 个策略组 |
| 实验组 | 每个实验组至少配置 1 个策略组 |
| 新增实验组 | 新增后需配置对应策略组 |
| 删除实验组 | 删除实验组时同步删除该组下策略组配置 |
| 分桶未配置 | 分桶未配置完成时，不允许发布实验 |
| 策略组未配置 | 任一实验组或对照组未配置策略组时，不允许发布实验 |

## 11.7 单条策略配置项
每个策略组内支持添加多条策略，每条策略包含以下配置项：

「策略类型」：下拉单选，必填，支持实时策略、离线策略、全量参竞。  
「实验策略」：下拉选择，必填。  
「覆盖人数」：选择实验策略后自动回显。  
「参竞策略」：自动回显，根据所选实验策略展示正向策略或反向策略。  
「出价配置模式」：单选，支持固定出价、模型出价。  
「参竞比例」：仅当策略类型为全量参竞时展示，输入范围 1% - 100%。  
「出价详情」：动态配置区，根据出价方式和出价配置模式联动展示。

 仅展示策略工厂中状态为“已发布”的策略。  
 仅展示当前实验所选媒体下的策略。  
 仅展示当前实验所选 RTAID 下的策略。  
 草稿、已下线、已停用策略不可被选择。

# 十二、出价配置
## 12.1 华为出价能力范围
本期平台在华为 RTA 中仅支持以下出价方式：

 出价系数。  
 CPA 出价。  
 CPC 出价。

暂不支持：

 CPM 出价。  
 CPD 出价。  
 CPI 出价。  
 oCPC 单出价。  
 oCPC 双出价。  
 创意级调价。  
 DPA 商品级调价。

---

## 12.2 出价系数
平台字段：

 出价系数。

华为字段：

 priceWeight。

校验规则：

 必填。  
 仅支持输入大于 0 的数值。  
 最大值为 50。  
 不允许输入 0。  
 不允许输入负数。  
 超过 50 时不允许保存。

---

## 12.3 CPA 出价
平台字段：

 CPA 出价。

华为字段：

 price.cpa。

校验规则：

 必填。  
 仅支持输入大于等于 0 的数值。  
 不允许输入负数。  
 出价范围按华为投放端账户 / 任务限制执行。

---

## 12.4 CPC 出价
平台字段：

 CPC 出价。

华为字段：

 price.cpc。

校验规则：

 必填。  
 仅支持输入大于等于 0 的数值。  
 不允许输入负数。  
 出价范围按华为投放端账户 / 任务限制执行。

---

## 12.5 出价配置模式
平台支持两种出价配置模式：

 固定出价  
 模型出价

固定出价：

 用户手动输入出价系数、CPA 出价或 CPC 出价  
 系统按用户配置返回固定值

模型出价：

 系统根据模型字段返回出价  
 模型字段来自策略工厂的数据字段配置  
 当前单个策略仅支持一个模型字段
