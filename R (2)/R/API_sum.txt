# **<font style="color:rgb(47,117,181);">1. 需求背景与目标</font>**
<font style="color:rgb(36,52,71);">平台需要把广告投放带来的后链路转化事件回传给对应媒体，用于媒体归因、转化统计和投放优化。转化来源包括</font><font style="color:rgb(36,52,71);"> H5 落地页、小程序和 APP。</font>

<font style="color:rgb(36,52,71);">本次需求目标是确认各媒体能否接入，并把媒体差异收敛为平台可配置的字段和事件对应关系。</font>

# **<font style="color:rgb(47,117,181);">2. </font>****<font style="color:rgb(47,117,181);">平台回传规则</font>**
| **<font style="color:rgb(255,255,255);">转化来源</font>** | **<font style="color:rgb(255,255,255);">平台既定识别方式</font>** | **<font style="color:rgb(255,255,255);">产品规则</font>** |
| --- | --- | --- |
| <font style="color:rgb(36,52,71);">H5 落地页</font> | <font style="color:rgb(36,52,71);">click_id</font> | <font style="color:rgb(36,52,71);">从广告投放链接取得媒体点击标识；回传时转换为媒体要求的字段名。</font> |
| <font style="color:rgb(36,52,71);">小程序</font> | <font style="color:rgb(36,52,71);">click_id</font> | <font style="color:rgb(36,52,71);">从小程序启动或跳转参数取得媒体点击标识；只有媒体明确支持且参数可完整保留时才开放。</font> |
| <font style="color:rgb(36,52,71);">APP</font> | <font style="color:rgb(36,52,71);">callback / callback_url</font> | <font style="color:rgb(36,52,71);">优先保存监测链接下发的回调参数并原样使用。若媒体官方方案只支持设备标识、</font><font style="color:rgb(36,52,71);">click_id 或 Install Referrer，则按该媒体方式接入，并在产品上标注为例外。</font> |

### <font style="color:rgb(31,77,120);">对接说明</font>
+ 由广告主提供回调url，即feedback url：接收亿米请求的点击数据；（接口一）；
+ 当用户点击广告时，亿米点击处理后台会获取相关参数，添加到feedback url，发起请求，同步给广告主；
+ 广告主需要搭建服务，对亿米的请求url 进行处理，并记下相关参数；
+ 当广告主收到APP 某种转化类型请求时，比对该转化类型数据与上述记下的点击数据，如果有亿米平台7 天内带来的，则将亿米点击追踪ID 等信息回传亿米平台，（接口二）。

| APP 上传 | 接口一 | 当用户点击广告时，亿米点击处理后台会获取相关参数，添加到feedback url，发起请求，同步给广告主，请求格式如下（请不要直接复制该链接，如果要复制该链接，请检查最终链接是否含有空格、回车等特殊字符）：<br/>https://xxx.com/track/click?response_validate=false&imei=__IMEI__&oaid=__OAID__&click_time=__TS__&app_id=__APPID__&adid=__ADID__&campaign_id=__CAMPAIGNID__&callback=__CALLBACK__&sign=__SIGN__&ua=__UA__&ip=__IP__&adName=__ADNAME__ |
| --- | --- | --- |
| | 接口二 | 上报方式：广告主在收到APP 发生该种转化类型后，必须 实时 将关联后的效果上报亿米平台，以免出现统计无效的情况。<br/>回调地址：<br/><br/>非关键行为：https://trail.e.mi.com/api/callback?callback={callback_param}&imei={imei}&oaid={oaid}&conv_time={conv_time}&convType={convType}&sign={sign}<br/><br/>关键行为：https://trail.e.mi.com/api/callback?callback={callback_param}&imei={imei}&oaid={oaid}&conv_time={conv_time}&convType={convType}&key_action_type={key_action_type}&key_action_target={key_action_target}&key_action_threshold={key_action_threshold}&key_action_reach={key_action_reach}&sign={sign}<br/><br/> |
| H5上传 | 接口 | 广告投放时，会将线索相关参数拼接到落地页上, 广告主的服务器端根据网址地址请求日志，将拼接了参数的网址地址和用户线索做映射，把符合转化条件的用户参数通过回传地址实时上报给小米服务器。回传地址形如<br/>https://site.e.mi.com/conversionLog?conversionId=__CONVERSIONID__&conversion_debug=true&eventType=form&clientTime=__CONVTIME__&logExtra=__LOGEXTRA__&webConversionId=__WEBCONVID__&convType=__CONVTYPE__ |
