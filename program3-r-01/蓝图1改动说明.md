## 二、新增横切面一：执行边界分级

原蓝图完全没有的内容，插在"总体系统边界"之后。

### 2.1 总原则

> **增支 ≠ 减支**：增支（提价/加预算/换素材）错了会烧钱，损失无上限 → 必须人工确认；减支/止损（降价/暂停/减预算）错了只是少花，损失有上限 → 可自动 + 护栏。

### 2.2 四级分级

| 级别 | 定义 | 典型动作 | 触发方式 |
|---|---|---|---|
| L0 只读/只告警 | 零资金风险，只通知不落地 | 企微告警、报表推送、趋势报告 | 自动 |
| L1 人工确认后执行 | 有资金风险，人点确认才落地 | 提价、加预算、素材替换、放量、采纳预测方案 | 人工 gate |
| L2 有护栏的自动 | 低风险可逆，带护栏自动执行 | 降价、减预算、调价监测任务创建 | 自动 + 护栏 |
| L3 紧急止损全自动 | 不执行损失更大，秒级自动 + 强留痕 | 合规暂停、风控阻断 | 自动（唯一例外） |

### 2.3 L2 护栏四要素（文档内已列）

幅度上限（单次降价 ≤20%）、方向限制（只减支）、白名单、可撤销。

## 三、新增横切面二：载体设计

### 3.1 载体三要素

算力位置（后端/边缘/端上）× 入口（IM/Web/API/无UI）× 形态（对话框/抽屉/SDK/守护）。

### 3.2 五类载体

IM 平台 / Web 内嵌面板 / SDK-API / 定时任务守护进程 / 边缘端上 Agent。

### 3.3 逐场景载体分派

| 场景 | 载体 | 决策依据 |
|---|---|---|
| 一 竞价感知 | 边缘/守护进程 | 毫秒级，算力靠近网关 |
| 二 效果预测 | Web 面板 | 看报告+置信区间 |
| 三 智能预警 | IM 推送 + Web 面板 | 告警秒达，处理回 Web |
| 四 应急暂停 | IM 强提醒（通知）+ API/守护进程（执行） | 秒级执行走 API |
| 五 趋势分析 | Web 面板 | 看图表趋势 |
| 六 优化建议 | Web 面板（IM 通知） | 采纳在 Web |
| 七 NL 查询 | IM | 对话式问数 |

### 3.4 IM 三条红线

看不了复杂数据 / 做不了审阅式决策 / 消息流会淹没。

## 四、每场景追加"执行边界 + 人工确认点"

7 个场景各追加两张表，并附修改点/注意说明：

### 场景一 实时竞价感知
- 执行边界：⑫告警 L0、⑩创建任务 L2、⑪提价 L1、⑪降价 L2
- 确认点：1-1 提价采纳（A）、1-2 降价回滚（B）、1-3 白名单（C）
- 修改点：⑪执行出价调整 → 默认只告警（L0）+ 生成调价建议（L1），仅降价方向且护栏内才 L2 自动

### 场景二 投放效果预测
- 执行边界：⑩报告 L0、⑪采纳 L1、⑫创建任务 L2
- 确认点：2-1 采纳方案（A）、2-2 护栏配置（C）
- 注意：采纳 = 确认"按预测执行"，必须显式

### 场景三 智能分析及预警
- 执行边界：⑦a告警 L0、⑦b-1暂停 L2/L3、⑦b-2提价 L1、③创建任务 L2
- 确认点：3-1 执行方式（C）、3-2 提价确认（A）、3-3 恢复（B）、3-4 告警处理（A）
- 修改点：⑦b拆成"自动暂停 + 调价建议"；提价必须有人点，暂停可自动

### 场景四 人工干预与紧急暂停
- 执行边界：⑧选择级别（人工）、⑪暂停 L3、⑫阻断 L3、⑭快照留痕、⑮通知 L0
- 确认点：4-1 操作级别（A）、4-2 恢复确认（A）、4-3 授权范围（C）
- 注意：自动暂停可秒级，恢复投放绝不能自动

### 场景五 趋势分析与洞察
- 执行边界：⑩报告 L0、⑪追踪任务 L0/L2
- 确认点：5-1 追踪任务可选确认（C）
- 注意：纯分析，默认只出报告不自动追踪

### 场景六 优化建议生成
- 执行边界：⑨展示 L0、⑩一键采纳 L1、⑫素材替换 L1、⑫预算加码 L1、⑫减支 L2
- 确认点：6-1 一键采纳（A）、6-2 素材/加码单独确认（A）、6-3 回滚（B）
- 修改点：⑫三个动作拆开；一键采纳拆成"减支类全采纳 + 增支类逐项确认"

### 场景七 自然语言查询

- 确认点：无（纯查询零执行）
- 注意：口径修改属数据治理，不进本清单

## 五、场景二数据流改造（唯一动过的 flowchart）

### 原画法问题
1. **数据归属模糊**：③"查询历史消耗/激活/开户/ROI"全从报表中心查，但激活/开户是归因平台的数据
2. **路径不对称**：行业数据直连模型引擎，归因数据绕道报表中心

### 新画法
```
③a 取投放数据 ──┐
③b 取转化数据 ──┼──→ ⑤三方平权汇合 → ⑥对齐(时间/维度/口径) → ⑦特征工程(衍生特征)
③c 取行业数据 ──┘                                      ↓
                                           ⑧特征数据集 → ⑨模型推理
```

### 新增"特征数据集说明"表
| 特征层 | 来源 | 示例 |
|---|---|---|
| 直接特征（投入侧） | 报表中心 | 昨日消耗、曝光、出价、预算利用率 |
| 直接特征（产出侧） | 归因平台 | 近7日收敛激活、入金、激活→入金转化率 |
| 直接特征（参照系） | 媒体行业大盘 | 行业平均CPA、竞品出价水位 |
| 衍生特征（跨方计算） | 三方拼合 | 实际CPA、我vs行业差、CPA环比、出价弹性、ROI趋势斜率 |
